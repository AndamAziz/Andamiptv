# Inbox - لینکی M3U لێرە دابنێ

**کوردی:** لیستێکی M3U (بۆ نموونە «کۆپی وەک M3U») لێرە دابنێ:
GitHub ← Andamiptv ← library ← inbox ← **Add file ← Create new file**، ناوێک بنووسە کە بە `.m3u` کۆتایی بێت
(بۆ نموونە `fool-night.m3u` یان `fool-night tv=326247.m3u`)، لیستەکە paste بکە و **Commit changes** دابگرە.
چەند خولەکێک دوای ئەوە: ئەڵقە و فیلمە نوێ و ساغەکان بە TMDB ID، پۆستەر و گرووپی دروست دەچنە ناو playlist.m3u.
لینکی تۆکندار، کار نەکردوو، کەناڵی زیندوو و دووبارەکان زیاد ناکرێن. هیچ شتێک لە پلەیلیستەکە ناسڕدرێتەوە.
ئەنجام: Actions ← Inbox import ← Summary. دوای ئەوە دەتوانیت فایلەکە بسڕیتەوە (کاری لەسەر پلەیلیست نییە).

**English:** put an M3U list here (Add file → Create new file / Upload files, name ending in `.m3u`;
`tv=ID` / `movie=ID` in the file name is optional). The inbox-import workflow adds the new, playing,
token-free episodes / movies with a TMDB id in the playlist format. Nothing is ever removed.
